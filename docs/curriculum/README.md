# Bet Track source

`bet-track.json` is the canonical six-lesson Bet curriculum. Run `scripts/build_bet_track.py` with Python containing Pillow, fontTools and reportlab to generate the online page and 16-page printable together. The illustrations are in `public/images/bet-track/`. The former duplicated Bet DOCX has been replaced by this editable source; Aleph and Gimel retain their existing sources.

Each lesson teaches new consonants and vowel constructs before practice, includes meanings and feedback, and maps to two workbook pages. Page 14 contains the readiness review; pages 15 and 16 contain the teacher practice key.
